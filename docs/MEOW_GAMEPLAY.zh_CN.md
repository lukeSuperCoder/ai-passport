# Meow 完整玩法机制

本文档从玩家和设计实现两个角度说明 Meow 的完整玩法。它描述的是 `demo/meow` 游戏规则；桌面单机模拟器保留养成、背包、小游戏、旅行、进化和收集，网络相关能力见“版本差异”。

## 1. 游戏定位与目标

Meow 是一款三键电子宠物养成游戏。玩家需要孵化并照顾宠物，通过护理、小游戏和旅行获得经验与物资，使宠物从幼体成长为成体，并逐步点亮宠物、成就、道具和纪念品图鉴。

游戏没有传统的最终通关画面，长期目标包括：

- 维持饱食、清洁、健康和心情，避免宠物离开。
- 达到年龄与等级的双重要求，完成全部成长阶段。
- 通过护理方式影响少年和成体形态。
- 提高五种游戏的成绩，持续获取养成物资。
- 收集全部宠物形态、成就、道具和旅行纪念品。

核心循环如下：

```text
观察状态
  → 护理或使用背包物品
  → 玩小游戏、遛弯或旅行
  → 获得经验和物资
  → 升级与进化
  → 解锁图鉴
  → 继续照顾更高阶段的宠物
```

## 2. 页面结构与操作

底栏包含五个主页面：主页、背包、游戏、图鉴、设置。

| 输入 | 通用行为 |
| --- | --- |
| 短按 `UP` / `DOWN` | 在底栏、列表或当前页面的动作之间移动 |
| 短按 `OK` | 进入页面、选择条目或执行高亮动作 |
| 长按 `OK` | 返回上一级、取消当前选择或提前结束小游戏 |
| 长按 `UP` / `DOWN` | 背包和图鉴切换分类；三消跳到轴线尽头；旅行调整并确认出发 |
| 息屏时任意键 | 唤醒设备；唤醒用的第一次点击不会继续触发游戏动作 |

主页提供喂食、洗澡、医疗、开关灯四个快捷动作。前三个动作会按固定目录顺序寻找当前可以使用的物品，跳过无效或缺货项目。

## 3. 生命周期、年龄与等级

### 3.1 时间尺度

- 1 游戏分钟等于 60 秒真实时间。
- 蛋固定经过 60 秒真实时间孵化，不使用游戏分钟累计。
- 退出或断电后会根据墙上时钟补算状态，单次最多补算 8 小时。
- 宠物睡觉时暂停常规饱食和清洁衰减。

### 3.2 成长阶段

| 当前阶段 | 进入下一阶段所需年龄 | 最低等级 | 进化后的基础状态与礼物 |
| --- | ---: | ---: | --- |
| 蛋 | 真实 60 秒 | — | 幼体：饱食 80、清洁 90、健康 90、心情 70，Lv.1 |
| 幼体 | 40 游戏分钟 | Lv.4 | 儿童：90 / 85 / 95 / 80，赠送水果和矿泉水 |
| 儿童 | 120 游戏分钟 | Lv.8 | 少年：95 / 85 / 100 / 85，赠送维生素和沐浴露 |
| 少年 | 240 游戏分钟 | Lv.14 | 成体：100 / 90 / 100 / 90，赠送维生素和毛巾 |
| 成体 | 不再进化 | 最高 Lv.99 | 继续养成和收集 |

年龄和等级必须同时满足。年龄足够但等级不足时，宠物会停留在当前阶段。

### 3.3 经验与等级限制

升级所需经验为：

```text
当前等级升级经验 = 20 + (当前等级 - 1) × 8
```

各阶段存在等级上限：

| 阶段 | 等级上限 |
| --- | ---: |
| 幼体 | 5 |
| 儿童 | 12 |
| 少年 | 18 |
| 成体 | 99 |

经验来自有效护理、使用物品、玩耍、遛弯、旅行及设备版的拜访和对战。达到当前阶段等级上限后，不再为该阶段累计升级经验。

## 4. 四项核心状态

饱食、清洁、健康和心情的显示范围均为 0–100。

### 4.1 饱食

- 宠物醒着时按阶段和等级周期下降。
- 幼体基础衰减周期约为 18 游戏分钟；阶段越高周期越短，等级每提高约 8 级还会进一步加快。
- 不同阶段的单次下降量不同，高阶段下降更多。
- 饱食降至 0 的那次结算会造成肠胃问题并扣除健康。
- 食物和饮料可以恢复饱食，但不能超过 100。

### 4.2 清洁

- UI 显示的清洁度等于 `100 - 脏度`。
- 幼体基础变脏周期约为 22 游戏分钟；阶段和等级越高，变脏越快、单次增量越大。
- 油腻食物可能直接增加脏度。
- 洗澡、纸巾和部分健康饮食可以降低脏度。

### 4.3 健康

- 健康不会按固定钟点自然下降，而是由危险状态触发概率判定。
- 饥饿、脏污、便便、低心情会提高患病概率。
- 已经生病时，后续判定可能继续扣除健康。
- 两堆便便会直接引发寄生虫问题。
- 健康降到 0 时宠物离开，本轮养成结束。

### 4.4 心情

- 心情不使用独立的固定衰减时钟。
- 每游戏分钟，心情会向饱食、清洁和健康的平均水平靠拢。
- 生病、便便和睡觉时开灯会降低目标心情。
- 抚摸、遛弯、玩耍、食物和护理会即时提高心情。

## 5. 生病、便便与危险呼叫

疾病包括寄生虫、肠胃、感冒和咳嗽。对应药物可以移除病症，并获得额外健康回复；维生素是通用恢复品，但不替代所有对症治疗。

危险类型包括：饥饿、低心情、低健康、生病、便便过多和夜间开灯。

| 危险等级 | 数值阈值 | 提醒行为 |
| --- | ---: | --- |
| 警告 | 50% | 首次进入该档时响 1 声并显示提示 |
| 严重 | 30% | 首次进入该档时响 2 声；每 3 分钟可再次唤醒提醒 |
| 危急 | 10% | 首次进入该档时响 3 声；每 3 分钟可再次唤醒提醒 |

提示存在时画面显示红框；提示结束后允许再次息屏。状态恢复后，对应危险档位会重新计算。

## 6. 睡眠与灯光

- 默认睡眠时段为 21:00–08:00。
- 入睡和起床设置为相同小时表示关闭定时睡眠。
- 时钟有效时，宠物会按设置自动入睡和起床。
- 到睡觉时间仍未关灯，或存在饥饿、生病等危险时，设备会提醒“睡觉时间到了”。
- 睡着但灯仍开着时，可以继续喂食、清理和治疗。
- 关灯后，除开关灯外不能继续护理，但仍可玩小游戏。
- 睡眠期间不能开始旅行、拜访或对战。
- 夜间持续开灯会降低心情。
- “宠物睡觉”和“设备自动息屏”是两个独立状态。

## 7. 护理动作

| 动作 | 主要效果 | 条件与代价 |
| --- | --- | --- |
| 喂食 | 恢复饱食，部分食物提升心情或健康 | 消耗食物耐久；饱食已满时可能无法使用 |
| 喝水 | 恢复少量饱食，矿泉水补健康、可乐补心情 | 饮料位于食物分类，不产生便便 |
| 清理 | 清除便便，略微提升心情 | 使用垃圾袋或纸巾 |
| 洗澡 | 去除脏污和便便，提升心情 | 使用沐浴露或毛巾；地面干净时仍可获得心情收益 |
| 治疗 | 移除疾病并恢复健康 | 对症药效果更高；维生素提供通用恢复 |
| 抚摸 | 心情 +12 | 心情未满时有效 |
| 遛弯 | 心情 +10、饱食 -8，并获得材料 | 需要宠物醒着；金铲铲可增加一份掉落并消耗耐久 |
| 玩耍 | 提升心情并获得经验 | 通过游戏页进入五种玩法 |
| 开关灯 | 改变房间灯光状态 | 睡觉时也可执行 |
| 睡觉 | 关灯并进入睡眠 | 白天午睡会在后续分钟刷新时结束 |

主页自动选物品的优先顺序：

- 喂食：汉堡 → 饭团 → 沙拉 → 水果 → 矿泉水 → 可乐。
- 洗澡：沐浴露 → 垃圾袋 → 纸巾 → 毛巾。
- 医疗：驱虫药 → 胃药 → 感冒药 → 咳嗽药 → 维生素。

## 8. 物品与背包

背包分为食物、药品、道具三类，共 16 种物品。每种最多堆叠 999 份。

每份物品具有独立耐久概念：使用时先扣当前打开物品的耐久，耐久耗尽后才从背包数量中扣除一份。

### 8.1 食物

| 物品 | 饱食 | 心情 | 健康 | 其他效果 |
| --- | ---: | ---: | ---: | --- |
| 汉堡 | +32 | +4 | — | 脏度 +6、增重、延迟排便，计为油腻饮食 |
| 饭团 | +22 | +2 | — | 延迟排便 |
| 沙拉 | +14 | +8 | +4 | 略微清洁，计为健康饮食 |
| 水果 | +12 | +10 | +2 | 计为健康饮食 |
| 矿泉水 | +8 | — | +2 | 略微清洁，计为健康饮食，不排便 |
| 可乐 | +10 | +12 | — | 略微变脏、增重，计为油腻饮食，不排便 |

### 8.2 药品

| 物品 | 效果 |
| --- | --- |
| 驱虫药 | 治疗寄生虫；对症时提供额外健康回复 |
| 胃药 | 治疗肠胃问题；对症时提供额外健康回复 |
| 感冒药 | 治疗感冒；对症时提供额外健康回复 |
| 咳嗽药 | 治疗咳嗽；对症时提供额外健康回复 |
| 维生素 | 健康 +14、心情 +6，属于通用恢复品 |

对症药基础健康回复为 +18，对上当前病症时额外 +12。

### 8.3 道具

| 物品 | 效果 |
| --- | --- |
| 沐浴露 | 大幅降低脏度并提升心情 |
| 垃圾袋 | 清除便便 |
| 纸巾 | 清除便便并降低部分脏度 |
| 金铲铲 | 可直接挖掘；遛弯时额外获得一份物资 |
| 毛巾 | 大幅降低脏度并提升心情 |

孵化完成后，初始背包会提供饭团、水果、矿泉水、沐浴露、垃圾袋、纸巾、胃药和感冒药。

## 9. 掉落与奖励

材料分为常见、少见、稀有和珍品四档：

- 常见：饭团、矿泉水、纸巾、垃圾袋等。
- 少见：较高价值食物、药物或洗护用品。
- 稀有：低概率的高级恢复物品。
- 珍品：驱虫药、金铲铲等。

等级越高，少见、稀有和珍品的掉落权重越大。主要获取渠道为遛弯、小游戏分数奖励、旅行，以及设备版的拜访、对战胜利和部分平局。

## 10. 五种游戏

### 10.1 接住小鱼

目标是在鱼落到底部前移动挡板接住它。

- `UP` 向左，`DOWN` 向右。
- 普通鱼 +30 分，金色锦鲤 +50 分。
- 每累计 100 分奖励一份随机材料。
- 每 100 分，下落速度提高 10%，挡板宽度缩小 10%。
- 300 分起，小鱼有 30% 概率左右游动，并有 30% 概率变为锦鲤。
- 之后每增加 100 分，游动概率和锦鲤概率各增加 30%。
- 速度、挡板宽度和概率强化在 500 分后停止增长。
- 漏接或长按 `OK` 后进入结算。

### 10.2 节奏大师

两条轨道分别对应 `UP` 和 `DOWN`，支持短音符与长音符。

| 判定 | 短音符 | 长音符 |
| --- | ---: | ---: |
| 良好 | 15 分 | 20 分 |
| 完美 | 20 分 | 25 分 |

- 按下对应键开始判定，长音符需要保持并在正确时机释放。
- 每累计 100 分奖励一份随机材料。
- 长按 `OK` 提前结束并进入结算。

### 10.3 小猫快跑

宠物固定在三列跑道底部，玩家左右换道拾取物品、躲避障碍。

- `UP` 左移，`DOWN` 右移。
- 每约 3 秒生成一道物品，16 种物品等概率出现。
- 碰到物品后立即加入本局奖励，并显示“物品名 +1”。
- 20 秒起，每 2 秒进行一次障碍生成判定，初始概率 30%。
- 30 秒和 40 秒后障碍概率分别提高至 60% 和 90%，50 秒后不再提高。
- 30 秒起，物品和障碍生成间隔每 10 秒缩短 10%，60 秒后固定为初始值的 70%。
- 60 秒起，下落速度每 10 秒提高 10%，100 秒后固定为初始速度的 140%。
- 撞到障碍或长按 `OK` 结束；结算只发放本局实际拾取的物品。

### 10.4 三消

- 棋盘为 6×6，每盘随机选择三种物品图标。
- `UP` 控制上下移动，`DOWN` 控制左右移动。
- 长按方向键跳到该轴线尽头。
- `OK` 选中格子；选中后只能移动到相邻一格，再按 `OK` 交换。
- 横向或纵向连接三个及以上相同图标即可消除。
- 消除后只让上方物品垂直落下补空，不移动周边列。
- 每消除一个图标获得 10 分，并增加 1 秒时间。
- 无法形成消除的交换会退回原位。
- 初始时间为 60 秒。
- 每累计 100 分奖励一份随机材料。
- 当前棋盘无可行交换时自动生成下一盘，分数和剩余时间保留。
- 选中时长按 `OK` 取消选择；未选中时长按 `OK` 提前结算。

### 10.5 背包旅行

旅行是异步的资源投资玩法。

- 从已有食物中选择种类与份数作为行李。
- 食物品质和总收益越高，旅行时间越长、带回物资越多。
- 收益以饭团的单次收益作为换算锚点。
- 投入份数增加时，总收益继续增加，但每份的边际收益递减。
- 携带至少 6 份食物后，旅行有机会带回收藏纪念品。
- 旅行期间宠物不在家，主页只保留背包相关状态，不能护理。
- 旅行期间仍可以玩其他小游戏。
- 旅行结束后自动进入统一结算页，并亮屏提示。

## 11. 进化形态

- 蛋、幼体和儿童各有固定形态。
- 少年存在两种形态。
- 成体存在六种形态。
- 成体选择包含随机因素，即使护理良好也保留约五分之一出现意外形态的机会。

进化倾向由综合护理分影响。概念上可表示为：

```text
护理倾向 ≈ 有效护理次数
         - 忽视次数
         + 健康饮食次数 / 2
         - 油腻饮食次数 / 3
         - 超重惩罚
         - 长期脏污等负面修正
```

沙拉、水果和矿泉水增加健康饮食记录；汉堡和可乐增加油腻饮食记录。体重超过健康区间后会逐步产生进化惩罚。

因此进化不是固定选择题，而是“护理方式改变概率分布，随机数决定最终形态”。

## 12. 图鉴与成就

图鉴包含四类：

| 分类 | 解锁规则 |
| --- | --- |
| 宠物 | 当前存档实际到达对应阶段或物种后点亮；包含蛋和十种成长形态 |
| 成就 | 完成破壳、开心、长大、吃饱、干净、壮实等养成目标，以及接小鱼或节奏大师达到 100 分 |
| 道具 | 背包曾获得对应物品后点亮，共 16 种 |
| 收藏 | 旅行带回对应纪念品后点亮，共 8 种 |

收藏纪念品包括贝壳、车票等。更换新蛋后，旅行收藏仍然保留；执行“重置游戏”则会清空背包、收藏和成绩，并让当前宠物直接离开。

## 13. 宠物离开与重新开始

- 健康降到 0 后，宠物进入离开状态。
- 离开后仍可查看和修改设置。
- 在“再来一颗”上按 `OK` 会创建新蛋并重新开始 60 秒孵化。
- 普通换蛋和完整重置的保留范围不同；完整重置会清空更多长期记录。

## 14. 设备版世界互动

本节属于硬件固件的完整规则，桌面单机版不启用。

### 14.1 寻找规则

- 双方需要选择相同动作：拜访或对战。
- 寻找约持续 8 秒，期间按 `OK` 可取消。
- 近距离优先通过 BLE 发现和连接；双方已连接同一局域网时也可使用 UDP。
- 蛋、已经离开、睡觉或正在旅行的宠物不能参加。

### 14.2 拜访

- 双方心情 +10，已满时保持 100。
- 双方各获得一份礼物。
- 拜访同时计入有效护理和经验来源。

### 14.3 对战

战力主要由阶段、健康、心情、饱食、生病状态和被忽视形态计算。基础思路为：阶段权重最高，再叠加健康和心情；饥饿、生病和被冷落会扣分。战力相同则使用随机数决胜。

- 胜利：心情 +12，并获得材料。
- 失败：心情 -10。
- 平局：心情不变，低概率获得遗留物品。

## 15. 存档机制

硬件版使用 NVS；桌面模拟器使用当前启动目录下的 `meow-simulator-save.bin`。

存档内容包括：

- 宠物阶段、物种、年龄、等级和经验。
- 饱食、清洁、健康、心情、疾病、便便、体重和灯光状态。

## 16. 桌面单机版差异

- 完整宠物生命周期、状态变化、睡眠和进化。
- 护理、背包、物品耐久和随机掉落。

- 真实硬件音频、电池变化和浅睡功耗行为。

## 17. 推荐的新手流程

1. 等待新蛋孵化，熟悉主页四项状态。
2. 先在背包确认初始食物、药品和洗护用品。
3. 保持饱食和清洁在 50 以上，出现便便及时处理。
4. 轮流玩接小鱼、节奏大师、跑酷和三消，积累经验与材料。
5. 不要只喂汉堡和可乐；混合沙拉、水果、矿泉水有利于健康形态。
6. 使用旅行获取长期收藏，但出发前先把宠物状态照顾好。
7. 达到阶段年龄后检查等级；若未进化，继续通过护理和游戏获取经验。
8. 留意 50%、30%、10% 呼叫，避免健康持续恶化。
