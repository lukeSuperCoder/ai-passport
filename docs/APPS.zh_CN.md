# Meow（本固件）

[English](APPS.md) | 简体中文

`demo/meow` 是**独立宠物游戏固件**，开机即宠物，不含通知、对讲机、天气、验证器。**语言、Wi-Fi、蓝牙、时钟、屏幕、声音、固件更新都在游戏里设置**，不必先刷 `main`。固件刷入后第一次开机 toast「长按确定全局返回」。

引脚和 BSP 边界见 [README.zh_CN.md](../README.zh_CN.md) 与 [AI 硬件开发指南](AI_HARDWARE_DEVELOPMENT_GUIDE.md)。

## 按键

三键 `UP` / `DOWN` / `OK` 共用 GPIO0 的 ADC 分压。

| 操作 | 效果 |
| --- | --- |
| 短按 `UP` / `DOWN` | 底栏在主页 / 背包 / 游戏 / 图鉴 / 设置之间移动；进页后在该页动作间移动。背包和图鉴里在当前分类的条目间移动 |
| 短按 `OK` | 进入当前页。页里执行高亮动作。主页快捷（仅图标）：喂食 / 洗澡 / 医疗 / 开关灯，前三项按目录顺序轮流用当前能用的商品（喂食含饮料，洗澡含清理）。用完后 toast 显示「用 饭团 x1」和饱食/清洁/健康/心情的加减。开关灯可在睡觉时用，夜里进主页会先停在灯上；睡觉且没关灯时，每次进主页都会提示「睡觉时间到了」。设置页有语言、名字、睡觉时段、Wi-Fi、蓝牙、时钟、屏幕、声音、更新、重置游戏（清空背包、收藏和成绩，宠物直接离开）。背包按分类使用带耐久的物品。游戏：上下切换接住小鱼 / 节奏大师 / 小猫快跑 / 三消 / 背包旅行，确定开始；旅行先选食物份数再出发；小游戏和旅行回来都进同一张结算页（奖励、响一声、亮屏），再按确定退出 |
| 长按 `OK` | 退出页内选择、退出设置子页，或退出玩耍小游戏 |
| 长按 `UP` / `DOWN` | 背包里切换吃喝 / 药品 / 道具；图鉴里切换宠物 / 成就 / 道具 / 收藏；背包旅行里长按上键减少份数，长按下键出发。名字和 Wi-Fi 密码键盘里按住会连移，再按住就按行跳 |
| 接小鱼 | `UP` 左，`DOWN` 右 |
| 节奏大师 | `UP` / `DOWN` 点按或按住；长按 `OK` 结束并进结算 |
| 小猫快跑 | `UP` 左，`DOWN` 右；当前宠物在底部，跑道往下跑。每 3 秒一道物品（16 种等概率），碰到就收，有拾取动画，上方提示「物品名 +1」。20 秒起每 2 秒 30% 出障碍，之后每 10 秒 +30%，50 秒后不再加。30 秒起物品和障碍间隔每 10 秒 −10%，60 秒后停在 70%；60 秒起下落每 10 秒 +10%，100 秒后停在 140%。撞上障碍或长按 `OK` 进结算 |
| 三消 | `UP` 上下，`DOWN` 左右，长按跳到该轴尽头。确定选中；选中后只能在周围 1 格移动，再确定交换。横竖连 3 个及以上先消失（周边不动），再由上方垂直落下补空，每个 +10 分、+1 秒。换不成会退回。每盘 3 种物品，无子可走进入下一盘，积分和剩余时间保留。开局 60 秒，到时结算；选中时长按确定取消选中，未选中时长按确定结束 |
| 拜访 / 对战寻找中 | `OK` 取消 |
| 蛋 | 新蛋直接开始 60 秒孵化，名字以后在设置里改。孵化中也能进设置 |
| 宠物离开后 | 在「再来一颗」上按 `OK` 开新蛋；仍可进设置 |
| 蓝牙配对码 | `OK` 确认，`DOWN` 拒绝 |
| 息屏时任意键 | 唤醒（第一次点击会被吃掉） |

顶部是名字和等级，右边两颗胶囊是本地时间和电量（稿上的金币/宝石位）。Wi-Fi / 蓝牙开着时画在中间：灰色=空闲，黄色=连接/广播中，深色=已连上。

画面铺满全屏奶油底，按 Ardot 的 240×320 五页来：圆形宠物（外圈经验进度）、饱食/清洁/健康/心情条（右侧显示数值）、主页四个快捷（喂食 / 洗澡 / 医疗 / 开关灯）、底栏主页/背包/游戏/图鉴/设置。阶段徽章（蛋 / 心 / 芽 / 闪电 / 星章）是去底贴纸，放在名字下方、宠物左上，数字等级画在徽章正下方，经验当前/升级所需再画在等级下面。第三页是背包（食物、药品、道具），不是金币店。图鉴分四类：宠物（已到达的物种）、成就、道具（当前拥有的物品）、收藏（旅行带回的纪念品）。玩耍只在游戏页。

## 生命周期

1 游戏分钟 = **60 秒真实时间**。蛋孵化固定 **60 秒真实时间**，不跟游戏分钟走。

| 阶段 | 游戏分钟 | 最低等级 | 进化瞬间 |
| --- | --- | --- | --- |
| 蛋 | 真实 60 秒 | — | 幼体：饱食 80 / 清洁 90 / 健康 90 / 心情 70，Lv.1 |
| 幼体 | 40 | 4 | 儿童：数值拉到 90 / 85 / 95 / 80，并送水果、水 |
| 儿童 | 120 | 8 | 少年：95 / 85 / 100 / 85，并送维生素、沐浴露 |
| 少年 | 240 | 14 | 成体：100 / 90 / 100 / 90，并送维生素、毛巾 |

成体是**随机物种**（六种成体，外加两种少年）。护理分会提高健康物种的概率，但仍有约五分之一会抽到意外形态。幼体和儿童各一种固定物种。饮食也算进护理分：沙拉、水果、矿泉水算健康；汉堡、可乐算油腻。体重过高或一直脏兮兮会拉低进化。只靠等时间不会长大：年龄到了但等级不够，会停在当前阶段。

数值是 0–100。经验来自喂食、洗澡、治疗、玩耍、遛弯、拜访和对战；本阶段封顶（幼 5 / 童 12 / 少 18 / 成 99）。醒着时饱食、清洁按固定间隔掉，间隔随阶段缩短、等级每 8 级再快一点；掉量也随阶段加大。健康不按钟点掉，而是按当前状态掷骰：饿、脏、便便、心情低会提高生病概率；已经生病时有机会再掉健康。饿到 0 的那一次饱食结算会伤肠胃并扣健康。心情不单独计时，每分钟朝「饱食、清洁、健康」的均值靠拢，生病、便便、夜里开灯会把目标拉低；护理和玩耍是短暂上推。两堆便便会生病（寄生虫）。对症下药额外补健康，维生素也能补。健康为 0 则结束。

| 物品 | 主要加成 |
| --- | --- |
| 汉堡 | 饱食 +32，心情 +4，脏 +6，增重，排便 |
| 饭团 | 饱食 +22，心情 +2，排便 |
| 沙拉 | 饱食 +14，心情 +8，健康 +4，略清洁 |
| 水果 | 饱食 +12，心情 +10，健康 +2 |
| 矿泉水 | 饱食 +8，健康 +2，略清洁 |
| 可乐 | 饱食 +10，心情 +12，略脏，增重 |
| 对症药 | 健康 +18，对上病再 +12 |
| 维生素 | 健康 +14，心情 +6 |
| 沐浴露 / 毛巾 | 大幅清洁，心情 +8 / +10 |
| 垃圾袋 / 纸巾 | 清便便；纸巾也去脏 |

掉落分四档：常见（饭团、水、纸巾、垃圾袋）、少见、稀有、珍品（驱虫、金铲铲）。等级越高，稀有和珍品的权重越大。

每种危险（饥饿、心情、体力、生病、便便、夜里开灯）都有**三档呼叫**：**50% / 30% / 10%**。饱食、心情、健康按这个百分比；新升一档会响 1 / 2 / 3 声，并显示如「饥饿 30%」，红框只在这条提示还在时闪。响完可以息屏；30% / 10% 会每 3 分钟醒过来再叫一声，然后继续睡。

时钟有效时（NTP 或在设置里对过时），宠物按设置 → 睡觉时段睡觉（默认 **21:00–08:00**）。入睡和起床设成同一小时则不按时钟睡觉。到点时若还没关灯、或仍有饥饿 / 生病等护理危险，会响起并提示「睡觉时间到了」（息屏也会到点叫醒）。睡觉且没关灯时，每次进主页都会再提示一次。灯还开着时仍可喂食、清理、治疗；关灯之后除开关灯外不能护理，会提示「正在睡觉」。小游戏仍可玩。背包旅行、拜访和对战需要醒着。夜里一直开灯会掉心情。

断电补算最多 **8 小时**真实时间。

## 护理

| 动作 | 作用 |
| --- | --- |
| 喂食 | 未满时按食物回复饱食（汉堡 +32，饭团 +22，沙拉 / 水果更少但抬心情）；油腻会排便、增重；消耗 1 点**耐久** |
| 喝水 | 矿泉水饱食 +8、略清洁；可乐饱食 +10、心情 +12；饮料不排便；矿泉水 / 可乐在食物分类里 |
| 清理 | 清便便，心情略升；消耗垃圾袋或纸巾的耐久 |
| 洗澡 | 清便便、去脏；地上已经干净时也可以抬心情；沐浴露或毛巾 |
| 玩耍 | 接住小鱼全屏：上左下右移挡板，普通鱼 +30、锦鲤 +50。每 100 分：随机 1 份材料、下落加快 10%、挡板窄 10%。300 分起小鱼有 30% 概率左右游（不出台），并有 30% 概率出金色锦鲤；之后每 100 分再各 +30%。速度、板宽、游动和锦鲤概率到 500 分后不再变。游戏页另有**节奏大师**：两轨下落，`UP`/`DOWN` 点按或按住；短按良好 15 / 完美 20，长按良好 20 / 完美 25。两种游戏都按每 100 分随机发材料，结算时相同物品叠份数，确定退出。第三项是**小猫快跑**：三列跑道，当前宠物钉在底部，上左下右换道；每 3 秒一道物品（16 种等概率），碰到就进本局奖励，有拾取动画，上方提示「物品名 +1」。20 秒起每 2 秒 30% 出障碍，之后每 10 秒再 +30%，50 秒后停在 90%。30 秒起物品和障碍间隔每 10 秒 −10%，60 秒后停在 70%；60 秒起下落每 10 秒 +10%，100 秒后停在 140%。撞上障碍结束，结算只发本局捡到的物品。第四项是**三消**：6×6 棋盘，每盘随机 3 种物品，上键上下、下键左右，长按跳转；确定选中后只能在邻格交换，横竖 ≥3 先消失（周边不动），再由上方垂直落下补空，每个 +10 分并加 1 秒，每 100 分随机 1 份材料。无子可走进入下一盘，积分和剩余时间保留。开局 60 秒。第五项是**背包旅行**：选已有食物和份数让宠物出门，食物越好或越多走得越久、带回越多（按饭团收益当量，总比当量多），但份均收益递减；带够 6 份起有机会捡到收藏纪念品（图鉴「收藏」里能看到）。旅行中主页只留背包、护理不能做，其它小游戏仍可玩。回来直接进结算页，响一声并亮屏，确定退出 |
| 抚摸 | 心情未满则 +12 |
| 遛弯 | 心情未满则 +10；饱食 −8；背包未满时总会捡到 1 份材料。带着**金铲铲**会多挖一份并消耗铲耐久 |
| 治疗 | 去掉生病，并可补 HP；对症药额外补体力 |
| 开关灯 | 切换房间灯（睡觉时也能按） |
| 睡觉 | 关灯并午睡（睡觉时也能按；白天会睡到下一分钟时钟刷新） |

## 世界

拜访和对战都在**世界**里。确定打开列表，再选拜访或对战，约 8 秒寻找。两边必须选同一个动作。寻找时会打开蓝牙，结束后关掉。近距离用蓝牙即可；只有 Wi-Fi 已经连上时才走局域网 UDP。蛋、已离开、睡觉中的宠物不能连。寻找时按 `OK` 取消。

拜访：双方心情 +10（已满则不变），并各拿一份礼物。对战比较战力（阶段、HP、心情、饥饿、生病、被冷落外形），平手看随机数。赢 +12 心情并掉落材料，输 −10，平局不变（有时也能捡到剩的）。

## 背包

第三页是背包，三个分类：

| 分类 | 物品 |
| --- | --- |
| 食物 | 汉堡、饭团、沙拉、水果；饮料：矿泉水、可乐 |
| 药品 | 驱虫、胃药、感冒药、咳嗽药、维生素 |
| 道具 | 沐浴露、垃圾袋、纸巾、金铲铲、毛巾 |

每种最多叠 999 份，并且都能用。**每份都有耐久**（打开那份会先扣耐久，扣完才少 1 份）。孵化时自带饭团、水果、矿泉水、沐浴露、垃圾袋、纸巾、胃药和感冒药。主页喂食 / 洗澡 / 医疗按目录顺序轮流用当前能用的商品（喂食：汉堡→饭团→沙拉→水果→矿泉水→可乐；洗澡：沐浴露→垃圾袋→纸巾→毛巾；医疗：驱虫→胃药→感冒药→咳嗽药→维生素），用不成的会跳过。使用后 toast 显示「用 饭团 x1」以及饱食/清洁/健康/心情的加减。也可以在背包里对着图标用。长按上 / 下键换分类。金铲铲可在背包里挖一次，遛弯时带着会多捡一份。遛弯、拜访、对战获胜，以及有时玩耍/平局会补充材料。

蓝牙配对界面仍可能出现；iPhone 通知不再当「有客人」。

## 图鉴

第四页，四个分类，交互和背包一样（短按上下在卡片间移动，长按上下换分类，确定 toast 两行介绍，不显示名字）。每个分类标签上显示已点亮/总数：

| 分类 | 内容 |
| --- | --- |
| 宠物 | 蛋和十种形态，按当前养成进度解锁 |
| 成就 | 破壳、开心、长大、吃饱、干净、壮实，以及接住小鱼 / 节奏大师满 100 分 |
| 道具 | 十六种物品（背包里有的才点亮） |
| 收藏 | 旅行带回的八种纪念品（贝壳、车票等，换蛋后仍保留） |

## 设置

底栏最后一页。蛋和死后也能进。

| 页 | 作用 |
| --- | --- |
| 语言 | 英语 / 简体中文（默认中文），写入 NVS |
| 名字 | 改宠物名字（留空确定用默认幼体名，长按返回）。升阶后一直保留 |
| 睡觉时段 | 宠物入睡/起床整点（确定 +1 小时；两行相同则不按点睡） |
| Wi-Fi | 电源、自动重连、扫描、加入（三键密码）、忘记网络 |
| 蓝牙 | 电源、停止广播、广播、忘记绑定 |
| 日期时间 | NTP 开关（默认开，切换即存）与服务器。关掉 NTP 后手拨年/月/日/时/分，最下行「对时」写入 |
| 屏幕 | 亮度 10–100%；自动休眠 从不 / 15 / 30 / 60 / 120 秒 |
| 声音 | 静音；音量 0–100% |
| 更新 | 当前/最新版本；检查；确认后安装。只下 `latest.json` 里的 **应用分区**（`url`，不是 `*-factory.bin`）。连上 Wi-Fi 后也会后台检查，弹出「确定安装 / 下键稍后」。宠物 NVS 保留。带新分区表的第一次 USB 烧录用 `idf.py flash`（不要 erase），或把 Release 里的 `*-factory.bin` 写到 `0x0`。 |

状态存在 NVS（宠物：命名空间 `app`，键 `meow`；设置同属 `app`；`ota_skip` 记住稍后的版本）。

每个 demo 一条通道（`ota/channel`，本分支是 `demo/meow`）。设备只拉 `main` 上的 `ota/demo/meow/latest.json`，清单里的 `channel` 对不上就拒绝。打标签 `demo-meow-vX.Y.Z`（或在本分支跑 **Release firmware**）只构建、只回写这一份，不动其它 demo。Release 两份：`FoloToy-AI-Passport-demo-meow.bin`（OTA 应用分区，设置 → 更新装这份）和 `FoloToy-AI-Passport-demo-meow-factory.bin`（`0x0` 整片）。不要每个提交都发版。

## 设备休眠

这是整机浅睡，不是宠物睡觉。空闲达到设置里的自动休眠时间后（设为从不则永不休眠）：

- 关背光、面板休眠、停 LVGL tick
- 关掉 Wi-Fi 和蓝牙；按键亮屏不立刻重连。亮屏满 **30 秒**仍未息屏，且 Wi-Fi 开关开着，才按已存网络重连（打开 Wi-Fi / 更新页会马上恢复射频）
- GPIO0 可唤醒 CPU；30% / 10% 呼叫也会定时醒过来再叫

菜单静止时整屏约 1 Hz 刷新，CPU 下限降到 40 MHz。进小游戏再拉回 4 Hz / 80 MHz。

寻找对方、呼叫提示还在响、设置子页开着、Wi-Fi 正在扫描/连接、正在检查或下载固件、或正在等配对码时**不会**浅睡。
