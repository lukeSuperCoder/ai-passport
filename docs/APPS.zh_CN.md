# 机上应用与设置

[English](APPS.md) | 简体中文

本文说明当前 `main` 固件里的首页应用、设置项、按键操作，以及掉电后仍会保留的配置。硬件引脚和 BSP 边界见 [README.zh_CN.md](../README.zh_CN.md) 与 [AI 硬件开发指南](AI_HARDWARE_DEVELOPMENT_GUIDE.md)。

界面语言为 **English** 或 **简体中文**，在设置里切换。下文用中文菜单名，括号内为英文界面对照。

## 按键约定

三键 `UP` / `DOWN` / `OK` 共用 GPIO0 的 ADC 分压。全局规则：

| 操作 | 效果 |
| --- | --- |
| 短按 `UP` / `DOWN` | 上下移动光标 |
| 短按 `OK` | 进入、切换或确认 |
| 长按 `OK` | 子页返回上一级；首页进入锁屏 |
| 任意键（休眠时） | 唤醒；若开了锁屏则先停在锁屏 |
| 锁屏上短按任意键 | 解锁 |

对讲机运行时：按住 `UP` 说话，松开停止；短按 `OK` 结束对讲。休眠、锁屏不会打断正在进行的对讲。

顶部状态栏显示本地时间、电量、蓝牙图标和 Wi-Fi 图标。图标灰色=射频已开但未就绪，黄色=连接/广播中，白色=已连接或 ANCS 就绪。射频关闭时对应图标隐藏。

## 首页

短按 `OK` 进入五项之一：

1. **通知**（Alerts）
2. **对讲机**（Walkie）
3. **天气**（Weather）
4. **验证器**（TOTP）
5. **设置**（Settings）

## 手机网页输入

连上 Wi-Fi 后，设备在同一局域网提供：

| 地址 | 用途 |
| --- | --- |
| `http://<ip>:8080/` | 扫码首页：把文字发到当前输入框（密码、关键字、城市、TOTP 密钥） |
| `https://<ip>:8443/w` | 对讲机网页麦（需接受自签证书） |
| `https://<ip>:8443/rtc` | WebRTC 对讲（需接受自签证书） |

不要用 80 / 443，也不要用微信内置浏览器。请用 Safari 或 Chrome。输入页上的 **QR** 会显示 `:8080` 的 HTTP 二维码。网页一次最多发送 160 个字符；设备弹出确认后按 `OK` 写入，长按丢弃。

## 通知（Alerts）

依赖 **设置 → 蓝牙** 与 iPhone ANCS：配对后在系统里打开「分享通知」。Mac 等主机可以绑定，但不能推 ANCS。

所有收到的 ANCS 都会写入最近记录（内存环形缓冲 16 条，界面最多显示 10 条）。是否弹出全屏提示，由关键字决定：

- **没有关键字**：每条通知都弹出，优先级为普通（`N`），播放「消息」提示音。
- **有关键字**：标题 / 副标题 / 正文命中任一关键字才弹出。英文关键字不区分大小写；中文按原文匹配。
- 关键字标为 `!`（高优先级）时播放「警报」提示音；`N` 播放「消息」提示音。
- 短信类通知若能解析出验证码，列表会放大显示数字。

| 操作 | 效果 |
| --- | --- |
| `UP` / `DOWN` | 浏览最近通知 |
| 长按 `UP` | 删除当前条 |
| 列表最下方的「设置」+ `OK` | 打开通知设置 |
| 弹出层 `OK` | 关闭；到时自动隐藏（见自动隐藏） |

### 通知设置

| 项 | 说明 |
| --- | --- |
| 返回 | 回到最近通知 |
| + 预设 | `code`、`otp`、`verify`、`验证码`、`校验码`、`动态码`。最多 8 条，每条最多 24 字符 |
| + 自定义 | 机上键盘，或扫码用手机网页填写 |
| 已有关键字 | `OK` 在 `N` → `!` → 删除 之间循环 |
| 自动隐藏 | `关` / `5s` / `10s` / `20s`。弹出后倒计时关闭；`关` 则一直等到按 `OK` |

默认：无关键字，自动隐藏 10 秒。关键字与优先级写入 NVS，通知正文不落盘。

## 对讲机（Walkie）

两台 Passport 选相同方式和频道即可对讲。离开本页会停止会话。

| 项 | 可选值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 方式 | WebRTC / 蓝牙 | WebRTC | WebRTC 走局域网 Wi-Fi；蓝牙走 BLE 广播/连接 |
| 频道 | 1–8 | 1 | 只与同频道对端互通 |
| 开始 | — | — | 启动后按住 `UP` 说话，`OK` 停止 |

WebRTC 需要已连 Wi-Fi。蓝牙方式需要蓝牙已开。手机可在同一局域网打开 `https://<ip>:8443/w` 或 `/rtc` 加入（自签证书）。设备只做信令与音频桥，不经过云。

音频为 8 kHz、20 ms 帧、ADPCM。方式和频道写入 NVS。

## 天气（Weather）

需要 Wi-Fi。主界面显示当前气温、体感、湿度、风、紫外线和穿衣建议；`UP` / `DOWN` 可看今天起共 4 天。`OK` 打开设置。锁屏在有缓存时显示一行城市天气。

拉取顺序：中国天气网（仅预设城市且有 `citykey`）→ Open-Meteo → wttr.in。自定义城市先走 Open-Meteo 地理编码。

### 天气设置

| 项 | 可选值 | 默认 |
| --- | --- | --- |
| 城市 | 在预设列表中循环 | 上海 |
| 自定义城市 | 键盘或网页输入地名，最长 32 字符 | — |
| 间隔 | 15 / 30 / 60 / 180 分钟 | 30 |
| 单位 | 摄氏·千米/时 或 华氏·英里/时 | 摄氏 |
| 立即更新 | 马上拉一次预报 | — |
| 完成 | 保存并返回 | — |

预设城市：上海、北京、广州、深圳、杭州、成都、武汉、南京、西安、香港、台北、东京、新加坡、伦敦、纽约。

休眠时暂停拉取。城市、坐标、间隔和单位写入 NVS。

## 验证器（TOTP）

标准 TOTP（HMAC-SHA1）。必须先在 **设置 → 日期时间** 把时钟校到大约 2023-11 之后，否则界面提示「请先在日期时间里校时」。

| 字段 | 规则 |
| --- | --- |
| 应用（issuer） | 最长 24 字符 |
| 账号（label） | 最长 32 字符 |
| 密钥 | Base32，或整段 `otpauth://totp/...` URI；最长 64 字符。网页粘贴更方便 |

URI 可带 `digits`（6 或 8，默认 6）和 `period`（15–120 秒，默认 30）。账号按应用名分组排序，存在 NVS。长按 `UP` 删除并二次确认。

## 设置（Settings）

| 项 | 作用 |
| --- | --- |
| 语言 | `OK` 在 English / 简体中文 之间切换，立即改界面 |
| Wi-Fi | 扫描、加入、忘记、网页二维码 |
| 蓝牙 | 开关、广播、绑定、忘记设备 |
| 日期时间 | NTP 或手动校时 |
| 屏幕 | 亮度、休眠、锁屏 |
| 声音 | 静音、音量、提示音 |
| 硬件 | 只读系统信息 |
| 调试日志 | 环形 ESP 日志 |

页脚固定显示 `Powered By Pax-z`。

### 语言

默认 English。只把 `lang` 写入 NVS，不改其它项。

### Wi-Fi

仅 2.4 GHz STA，最多列出 16 个 AP。`*` 表示需要密码。凭据在拿到 IP 后才写入 NVS。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 电源 | 开 | 关则断开并隐藏状态栏 Wi-Fi 图标 |
| 自动 | 开 | 开机/掉线后是否重连已存网络。认证失败约 3 次后停手，避免锁路由器 |
| 网页二维码 | — | 已获得 IP 时出现，打开 `http://<ip>:8080/` |
| AP 列表 | — | 开放网络直接连；加密网络进密码键盘（可预填已存密码）。键盘 `GO` 连接，`BK` 返回 |
| 重新扫描 | — | 再扫一遍 |
| 忘记网络 | — | 删除已存 SSID/密码，并停止自动重连 |

SSID 最长 32，密码最长 64。密码页也可扫码用手机网页填写。

### 蓝牙

广播名形如 `Passport-B4EC`。最多同时 2 路连接、6 个绑定。ANCS 仅 iPhone。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 电源 | 开 | 关则停止广播并断开 |
| 停止广播 | 开 | 已绑定设备都连上后不再广播；无绑定时仍广播以便首对 |
| 设备列表 | — | `*` 表示当前已连接。先选中再「忘记所选」 |
| 广播 | — | 手动开/关可发现；满员后无法再开 |
| 忘记所选 | — | 忘掉当前高亮设备 |

配对时状态栏/提示行显示 6 位码。数字对比：`OK` 同意，`DOWN` 拒绝。新绑定后可能进入「请开通知」，等 iPhone 打开分享通知；此时仍可广播给其它主机。

开关和「停止广播」、对端名称写入 NVS；绑定密钥由 NimBLE 自己存。

### 日期时间

时区固定 **CST-8**（UTC+8），界面无法改。

| 项 | 默认 | 说明 |
| --- | --- | --- |
| NTP | 关 | 开且 Wi-Fi 已连时同步。成功后提示「已同步」 |
| 服务器 | `pool.ntp.org` | 循环：`pool.ntp.org`、`time.apple.com`、`ntp.aliyun.com`、`time.windows.com` |
| 年 / 月 / 日 / 时 / 分 | — | 手动拨号；年 2024–2038 |
| 保存 | — | 把上面的拨号写入系统时钟 |

TOTP 和锁屏大时钟都依赖这里。NTP 开关和服务器索引写入 NVS；手动时间本身不单独存盘，掉电后若未开 NTP 需要重设。

### 屏幕

| 项 | 可选值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 亮度 | 10%–100%，步进 10 | 50% | 立即改背光 |
| 休眠 | 从不 / 15s / 30s / 60s / 120s | 30s | 无按键后关背光并让面板休眠。对讲、通知弹出、网页输入期间不计时 |
| 锁屏 | 开 / 关 | 开 | 休眠或首页长按 `OK` 后显示日期、大时钟、天气、电量 |
| 保持亮起 | 开 / 关 | 关 | 锁屏时不关背光 |

锁屏任意短按解锁。

### 声音

静音时所有输出为 0。否则音量 0–100，步进 10。

| 项 | 可选值 | 默认 |
| --- | --- | --- |
| 静音 | 开 / 关 | 关 |
| 音量 | 0%–100% | 70% |
| 消息 | 关 / 短音 / 双音 / 铃声 | 短音 |
| 警报 | 关 / 三连 / 警报 | 警报 |

切换时会试听当前音色（静音除外）。

### 硬件

只读：芯片、CPU、Flash / 分区、RAM / 堆 / 最低堆 / 最大块、PSRAM（本板为无）、Wi-Fi / 蓝牙 MAC、广播名、LCD、电池、ES8311、CW2017、芯片温度、运行时间、复位原因、IDF / 固件 / LVGL 版本。`UP` / `DOWN` 滚动。

### 调试日志

拦截 `ESP_LOG*` 到 48 行 × 32 字符的环形缓冲。`UP` / `DOWN` 滚动，滑到最新会跟随；`OK` 清空。不写入 NVS。

## 掉电保存

应用偏好在 NVS 命名空间 `app`。Wi-Fi / 蓝牙开关和凭据在各自命名空间。NVS 分区 24 KB，与系统及其它组件共用。

### `app`

| 键 | 类型 | 含义 | 出厂默认 |
| --- | --- | --- | --- |
| `lang` | u8 | 0=English，1=简体中文 | 0 |
| `bl` | u8 | 背光 10–100 | 50 |
| `sleep` | u16 | 休眠秒数，0=从不 | 30 |
| `lck` | u8 | 锁屏 | 1 |
| `lstay` | u8 | 锁屏保持亮起 | 0 |
| `vol` | u8 | 音量 0–100 | 70 |
| `mute` | u8 | 静音 | 0 |
| `tmsg` | u8 | 消息音色 0–3 | 1（短音） |
| `talert` | u8 | 警报音色 0 / 4 / 5 | 5（警报） |
| `ntp` | u8 | NTP | 0 |
| `ntps` | u8 | NTP 服务器索引 0–3 | 0 |
| `hide` | u8 | 通知自动隐藏秒数 | 10 |
| `wxc` | str | 城市名 | `Shanghai` |
| `wxlat` / `wxlon` | i32 | 纬度/经度 × 10000 | 312304 / 1214737 |
| `wxiv` | u16 | 天气间隔分钟 | 30 |
| `wxu` | u8 | 1=华氏 | 0 |
| `wkch` | u8 | 对讲频道 1–8 | 1 |
| `wkmd` | u8 | 0=WebRTC，1=蓝牙 | 0 |
| `kwn` + `kw` | u8 + blob | 最多 8 条关键字 | 空 |
| `totpv` / `totpn` / `totp` | u8 / u16 / blob | TOTP 账号，格式版本 2 | 空 |

### `bsp_wifi`

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `en` | 射频开关 | 开 |
| `auto` | 自动重连 | 开 |
| `ssid` / `pass` | 上次成功拿到 IP 的网络 | 无 |

### `bsp_ble`

| 键 | 含义 | 默认 |
| --- | --- | --- |
| `en` | 射频开关 | 开 |
| `quiet` | 满员后停止广播 | 开 |
| `pnames` | 已绑定设备显示名 | 空 |

擦除 NVS（例如 `nvs_flash_erase` 或量产空片）会恢复上表默认值，并忘掉 Wi-Fi 与 BLE 绑定。
