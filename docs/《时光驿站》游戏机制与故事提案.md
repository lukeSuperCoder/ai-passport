# 《时光驿站》游戏机制与故事提案

> 文档状态：概念提案 v0.1  
> 游戏类型：像素风、真实时间、三键操作、多宠物养成、轻度经营、旅行与故事收集  
> 核心体验：玩家与性格各异的宠物伙伴共同经营一间旅行驿站，让它在真实时间中持续生活、成长，并成为连接不同地区与角色的温暖据点。

## 1. 游戏概念

《时光驿站》是一款运行在掌上设备上的实时像素经营游戏。

玩家扮演一名离开城市、回到故乡的年轻店主，继承了祖辈留下的一间废弃驿站。驿站坐落在森林、山路、湖泊与旧车站的交界处。这里过去曾是旅行者交换消息、休息过夜，以及人与动物伙伴相识的地方；随着道路荒废，驿站和附近的小镇逐渐失去活力。

玩家将与最初遇见的宠物伙伴一起重新开张，随后结识更多不同物种、能力和性格的宠物。玩家负责做决定，宠物负责参与经营：接待客人、照料农园、制作商品、整理客房、采集材料、运送货物或前往远方旅行。

游戏的重点不是高频点击和精确计算，而是：

- 理解每只宠物的优点、缺点和愿望。
- 根据天气、时间、订单和事件安排合适的伙伴。
- 在利润、成长、关系与故事之间作出选择。
- 离开一段时间后，回来发现驿站里发生了新的事情。
- 看着破旧驿站和周边小镇在四季中逐渐恢复生机。

一句话定位：

> 在一间随真实时间运转的像素驿站里，和宠物伙伴分工经营、接待旅人、探索远方，并收集每一次相遇留下的故事。

## 2. 设计支柱

### 2.1 低压力的真实时间

真实时间用来制造生活感、等待感和重逢感，而不是惩罚玩家。

- 昼夜、天气、访客和旅行都随现实时间变化。
- 玩家不在线时，宠物会依照安排继续工作。
- 错过时段不会导致宠物死亡、作物永久枯萎或珍贵事件消失。
- 重要来访会留下信件、预约、照片或值班记录。
- 高频上线增加互动与故事，但不会形成压倒性的资源优势。

### 2.2 多宠物分工经营

每只宠物都由物种、属性、性格、技能和关系共同定义。不存在适用于所有场合的最强宠物，也不通过固定职业锁死成长方向。

### 2.3 经营结果必须成为故事

任务结算不只显示金币和材料。宠物的组合、性格与经历会让同一份工作产生不同的小事件、对话、照片和关系变化。

### 2.4 世界必须肉眼可见地成长

驿站升级、季节变化、NPC迁入和宠物加入，都应直接改变主场景。长期进度首先体现在像素世界的外观和活动中，其次才是数字。

### 2.5 三键也能做出有意义的决定

操作简单不等于选择简单。游戏通过安排谁、选择什么任务、怎样处理事件和把资源投向哪里产生策略，而不是依靠复杂输入。

## 3. 玩家幻想与长期目标

玩家从一间漏雨的小屋开始，最终将这里建设成闻名各地的星光驿站。

长期目标包括：

- 修复并扩建驿站的所有设施。
- 让周边荒废的小镇重新繁荣。
- 认识并邀请不同宠物伙伴入住。
- 培养不同岗位的宠物队伍和默契搭档。
- 完成宠物个人故事，帮助它们实现愿望。
- 结识来自不同地区的旅客并完成他们的故事线。
- 解锁森林、山谷、湖泊、海港、雪原等旅行地区。
- 收集旅行日记、照片、地方特产、配方和纪念品。
- 经历四季节庆，逐步揭开驿站衰落与祖辈失踪旅行的真相。

游戏没有传统意义上的结束。主线完成后，驿站继续经营，新的旅客、委托、旅行组合和收藏仍会出现。

## 4. 核心循环

### 4.1 每次打开设备

```text
查看驿站近况
  → 阅读离线报告和重要事件
  → 领取加工、旅行与订单结果
  → 根据当前时间、天气和需求调整安排
  → 亲自参与一次互动或工作
  → 扩建设施、培养宠物或准备下一段离线任务
```

一次典型会话为 2～5 分钟。

### 4.2 每个现实日

```text
清晨制定今日重点
  → 白天生产、接待、采集与送货
  → 黄昏处理住宿和晚餐高峰
  → 夜晚结算、交流、休息并安排长任务
```

玩家不必参与全部阶段。当天首次打开游戏时，可以补看之前发生的重要内容。

### 4.3 长期循环

```text
经营获得金币、材料与口碑
  → 建设新设施
  → 开放新岗位和配方
  → 吸引新旅客与宠物
  → 组建更丰富的队伍
  → 探索更远地区
  → 获得故事和稀有资源
  → 继续升级驿站与小镇
```

## 5. 真实世界时间

### 5.1 昼夜时段

游戏跟随设备所在时区，但将一天压缩为四个容易理解的时段。

| 时段 | 现实时间 | 氛围与主要内容 |
| --- | --- | --- |
| 清晨 | 06:00–10:59 | 早餐、送货员、农夫、晨间采集 |
| 白天 | 11:00–16:59 | 普通旅客、商人、农园和工坊生产 |
| 黄昏 | 17:00–20:59 | 住宿高峰、晚餐、归队和小镇居民来访 |
| 深夜 | 21:00–05:59 | 夜行客、神秘事件、值班与宠物休息 |

时段影响背景、音乐、客人类型、部分商品需求和事件概率，但不限制玩家使用基础功能。

### 5.2 任务时长

任务使用少量固定档位，帮助玩家形成直觉。

| 时长 | 任务示例 |
| ---: | --- |
| 5～15 分钟 | 泡茶、烹饪、整理客房、短训练 |
| 30～60 分钟 | 加工商品、河边钓鱼、附近采集 |
| 2～4 小时 | 森林探索、小镇送货、建筑施工 |
| 8～12 小时 | 区域旅行、远方订单、夜间值班 |
| 20～24 小时 | 长途旅行、重大建设、稀有研究 |

不使用难以记忆的零碎时长。玩家应能自然地在午休、上课、工作或睡前安排任务。

### 5.3 游戏季节

昼夜与现实同步，但季节采用加速日历：

- 每个游戏季节持续现实 14 天。
- 每季第 7 天举行小型集市。
- 每季第 14 天举行季度庆典。
- 现实 8 周经历一个完整游戏年。

季节影响作物、鱼类、天气、旅行区域、旅客和节庆。限定内容会在后续年份再次出现，不制造永久错过。

### 5.4 离线结算

离线期间只保存关键结果，不逐帧模拟。再次启动时首先显示摘要：

```text
离开期间：1天 7小时

接待旅客：12位
住宿收入：460
完成商品：面包×4、果酱×2
旅行归队：1支
重要事件：2件
伙伴状态：1位疲劳，其余良好
```

普通交易直接汇总，重要事件可以随后逐条查看。长期离线不会生成不可处理的数百条记录。

## 6. 三键操作框架

| 输入 | 通用行为 |
| --- | --- |
| 短按 `UP` / `DOWN` | 移动高亮、切换选项、调整数量 |
| 短按 `OK` | 进入、确认、执行当前动作 |
| 长按 `OK` | 返回、取消、关闭报告 |
| 长按 `UP` / `DOWN` | 切换分页、快速调整数量或跳转首尾 |

不设计需要同时按键的核心操作。所有关键选择均能在三层菜单内完成。

主页面优先呈现驿站像素场景。玩家通过底部热点切换：

```text
驿站 / 安排 / 伙伴 / 旅行 / 图鉴 / 设置
```

小游戏可以重新定义方向键含义，但必须在开始前显示简短提示。

## 7. 驿站空间与岗位

### 7.1 前台

负责入住、商品销售、咨询和特殊旅客接待。

- 主要属性：亲和、感知。
- 主要收益：金币、口碑、旅客情报。
- 事件倾向：议价、丢失物、隐藏身份、特殊请求。

### 7.2 厨房

把农产品和采集物制作成餐点，为住客提供服务。

- 主要属性：灵巧、专注。
- 主要收益：料理、住宿满意度、配方。
- 事件倾向：新配方、火候失误、偷吃、客人点单。

### 7.3 农园

种植蔬菜、水果、谷物、花卉和香草。

- 主要属性：灵巧、体力。
- 主要收益：基础食材、种子、品质作物。
- 事件倾向：天气、害虫、变异作物、小动物来访。

农园采用地块推荐动作：空地播种、干燥浇水、成熟收获，避免重复菜单操作。

### 7.4 工坊

把基础材料加工成果酱、面包、茶、奶酪、布料、家具和旅行用品。

- 主要属性：专注、灵巧或体力。
- 主要收益：高价值商品、建设部件、旅行装备。
- 事件倾向：节省材料、精品制作、设备故障、配方发现。

### 7.5 客房

整理房间、照顾住客并记录他们的需求。

- 主要属性：亲和、专注。
- 主要收益：住宿费、回头客、旅客故事。
- 事件倾向：深夜求助、遗留物品、住客留言、特殊布置。

### 7.6 采集

前往附近森林、河岸和山脚获取材料。

- 主要属性：感知、体力。
- 主要收益：木材、果实、蘑菇、药草、鱼类和种子。
- 事件倾向：迷路、天气变化、稀有地点、救助其他角色。

### 7.7 送货

完成小镇订单并维持与各地区的关系。

- 主要属性：体力、亲和。
- 主要收益：金币、小镇关系、地区特产。
- 事件倾向：道路阻塞、临时委托、收件人故事。

### 7.8 旅行

组成队伍前往远方，带回见闻、照片、纪念品、新伙伴线索和稀有材料。

- 主要属性：根据目的地变化。
- 主要收益：故事、收藏、区域资源。
- 事件倾向：分支路线、旅行选择、露营、陌生角色相遇。

## 8. 经营资源与生产链

资源分为五类：

| 类型 | 示例 | 主要用途 |
| --- | --- | --- |
| 基础材料 | 木材、石头、纤维 | 建设、工具、加工 |
| 农产品 | 小麦、草莓、香草 | 料理、商品、订单 |
| 地区材料 | 山泉水、海盐、雪莲 | 高级配方、旅行准备 |
| 商品 | 面包、果酱、茶、布料 | 销售、招待、送礼 |
| 收藏品 | 车票、贝壳、旧徽章 | 图鉴、故事和装饰 |

典型生产链保持短而清晰：

```text
小麦 → 面粉 → 面包
水果 → 果酱
香草＋山泉水 → 特调茶
羊毛 → 毛线 → 毛毯
木材＋布料 → 客房家具
鱼＋香草 → 旅行便当
```

多数商品最多经过两次加工，避免层级过深。直接出售原料更快，加工后利润更高，但会占用宠物和时间。

### 8.1 商店定价

商品只设置三档价格：

- 实惠：成交快，口碑略高。
- 标准：收益稳定。
- 精品：利润高，需要品质、客人偏好或高口碑支持。

不要求玩家逐件输入价格。

### 8.2 订单

订单分为：

- 日常委托：低风险、稳定收入。
- 旅客请求：推动人物故事。
- 小镇建设：消耗大量资源，永久改变世界。
- 季节订单：与节庆相关，期限宽松。
- 紧急请求：奖励较高，但可以拒绝且不会破坏主线。

## 9. 宠物伙伴系统

每只宠物由以下五部分组成：

```text
物种倾向
＋五项属性
＋性格特征
＋后天技能
＋与玩家及其他伙伴的关系
```

### 9.1 五项属性

| 属性 | 影响 |
| --- | --- |
| 体力 | 搬运、建造、采矿、连续工作时长 |
| 灵巧 | 种植、制作、钓鱼和产品品质 |
| 感知 | 探索发现、隐藏需求和风险预警 |
| 亲和 | 接待、照料、交易和协作 |
| 专注 | 研究、加工稳定性和复杂任务 |

界面使用 1～5 颗星表达，不向玩家展示复杂公式。

### 9.2 物种倾向

| 物种 | 擅长 | 相对短板 | 代表能力 |
| --- | --- | --- | --- |
| 猫 | 前台、客房、精细制作 | 重体力与水中工作 | 发现客人隐藏偏好 |
| 狗 | 探索、护卫、送货 | 精细研究 | 降低队伍遇险概率 |
| 兔 | 农园、采集、照料 | 长途与重体力任务 | 提高作物品质 |
| 熊 | 建设、加工、搬运 | 高压接待 | 有概率产出双份大型商品 |
| 狐狸 | 寻宝、交易、研究 | 重复性劳动 | 提高稀有事件概率 |
| 水獭 | 钓鱼、灌溉、水运 | 山地工作 | 提高水产品数量和品质 |
| 鸟 | 侦察、送货、采果 | 搬运与地下工作 | 缩短任务时间 |
| 羊驼 | 运输、纺织、远行 | 精密研究 | 增加队伍携带容量 |
| 松鼠 | 采集、仓储、种子 | 正面对抗 | 有概率节省或回收材料 |

物种只改变适性和事件，不限制宠物学习其他工作。

### 9.3 性格

性格同时包含优势与麻烦，以避免纯粹的强弱排序。

| 性格 | 优势 | 麻烦 |
| --- | --- | --- |
| 勤快 | 工作速度提高 | 疲劳积累更快 |
| 好奇 | 稀有事件概率提高 | 可能偏离原任务 |
| 贪吃 | 更容易发现料理配方 | 厨房偶尔损耗食材 |
| 胆小 | 提前发现风险 | 面对突发事件效率下降 |
| 热情 | 提高搭档与客人心情 | 自身体力消耗增加 |
| 独立 | 单独工作效率高 | 多宠协作效率较低 |
| 黏人 | 与玩家一起工作时增强 | 独自工作容易低落 |
| 爱干净 | 料理和客房品质提高 | 雨天农园与泥地工作不开心 |
| 冒失 | 偶尔出现意外双倍收益 | 也可能损失普通材料 |
| 囤积 | 常带回额外材料 | 偶尔占用携带空间 |

### 9.4 后天技能

技能通过实际参与工作解锁，而不是随意加点。

- 农园：育种、节水、丰收、温室照料。
- 厨房：控温、节材、调味、快速备餐。
- 前台：推销、鉴赏、安抚、熟客记忆。
- 探索：追踪、露营、寻宝、天气判断。
- 工坊：精工、维修、批量制作、材料回收。

每只宠物最多装备 2～3 个技能，形成明确但可改变的发展方向。

### 9.5 体力与心情

宠物只有两个需要管理的日常状态：

- 体力：影响是否能执行高强度或长时间任务。
- 心情：影响品质、事件倾向和协作表现。

过度工作不会导致死亡或永久离开，只会降低效率、拒绝高强度任务或主动休假。

恢复方式包括休息、喜欢的食物、与玩家互动、娱乐设施、和喜欢的搭档共事及参加节庆。

## 10. 多宠物安排与协作

### 10.1 每日安排板

```text
今日安排                 春 12日
────────────────
> 前台       墨墨 / 空位
  厨房       阿团
  农园       露露 / 栗子
  采集       未安排
  休息       泡泡
────────────────
预计：金币 120～160
```

玩家选择岗位后，再从宠物列表中安排或撤下伙伴。宠物卡片显示：

```text
墨墨 · 猫
适性：良好
收益：★★★☆
品质：★★★★
风险：★
状态：精神很好
提示：可能发现客人隐藏偏好
```

游戏可以提供“均衡”“订单优先”“金币优先”“成长优先”和“轻松工作”等建议方案，但不会自动给出唯一最优答案。

### 10.2 队长与搭档

每个岗位可安排 1～2 只宠物，部分升级岗位支持 3 只。

- 第一位为队长，决定主要效率和任务方式。
- 第二位提供辅助能力和组合事件。
- 第三位提高上限，但会增加协调成本。

典型组合：

- 熊＋猫：熊提高产量，猫负责品质检查。
- 狐狸＋狗：狐狸寻找稀有地点，狗降低危险。
- 水獭＋鸟：鸟寻找鱼群，水獭负责捕捞。
- 兔＋松鼠：兔提高作物品质，松鼠回收种子。
- 猫＋狗：猫理解客人偏好，狗安抚焦躁旅客。

### 10.3 宠物关系

共同工作、旅行、休息和处理事件会发展关系：

```text
陌生 → 熟悉 → 搭档 → 默契 → 挚友
```

高关系可以：

- 减少协作消耗。
- 解锁组合技能。
- 在任务中互相补救。
- 出现双宠待机动画和专属事件。
- 在旅行照片与日记中出现特殊内容。

关系也会产生轻量矛盾。矛盾不会永久破坏伙伴，而是影响短期效率并提供故事选择。

## 11. 玩家角色

玩家不是旁观的排班管理员。每天拥有 2 点“陪伴行动”，可以亲自参与两项活动：

- 帮助某个岗位，保证基础成功并提高收益。
- 与一只宠物散步、训练或谈心。
- 接待重要旅客并作出剧情选择。
- 亲自参加小游戏或旅行准备。

玩家参与某岗位时，更容易触发宠物个人故事并提升亲密度。“今天陪谁”既是经营选择，也是情感选择。

玩家可以选择一项专长：

- 农艺师：作物和天气应对更稳定。
- 工匠：建设与加工节省材料。
- 店主：销售与住宿收益更稳定。
- 探险家：旅行事件获得额外选项。
- 伙伴师：宠物关系和技能成长更快。

专长可以通过主线后期调整，不要求开档时作出不可逆选择。

## 12. 旅行系统

旅行是游戏最重要的离线期待机制。

### 12.1 出发准备

玩家需要决定：

- 目的地。
- 队长与搭档。
- 携带食物和工具。
- 旅行目标：材料、故事、伙伴线索或收藏。

界面给出范围预测：

```text
目的地：雾松森林
时间：约 4 小时
队伍：狗狗阿麦 / 狐狸小灯
安全：高
发现：较高
携带：旅行便当、旧地图
可能获得：药草、木材、未知纪念品
```

### 12.2 旅行经过

系统根据队伍、性格、装备、天气和目的地生成 2～4 个事件节点。玩家不在线时，宠物会依据性格自行选择；玩家回来后可以阅读过程。

某些关键事件会保留选择：

```text
阿麦和小灯发现一座被藤蔓遮住的石门。

↑ 使用旧地图寻找入口
↓ 先在附近露营观察
OK 做下标记后返回
```

### 12.3 旅行日记

归队后生成一页像素旅行日记，包括：

- 一张小型像素场景或合影。
- 2～4 句由宠物性格决定的描述。
- 收获、事件与关系变化。
- 可收藏的地点印章或纪念品。

同一地点因队伍不同，会出现不同描述和支线。

## 13. 旅客与故事系统

### 13.1 旅客类型

- 普通旅客：提供稳定经营收入与世界氛围。
- 小镇居民：推动建设和地区关系。
- 商人：出售种子、工具和地区商品。
- 回头客：拥有多阶段个人故事。
- 神秘旅客：与主线和祖辈往事有关。
- 宠物旅客：可能成为临时帮工或新伙伴。

### 13.2 客人记忆

重要旅客会记住玩家此前的行为：

- 是否提供过帮助。
- 曾经安排哪只宠物接待。
- 喜欢的房间、料理和商品。
- 玩家在关键对话中的选择。

再次到访时，旅客和宠物会主动提及过去，形成连续关系。

### 13.3 对话选择

对话通常提供两个方向和一个行动选项：

```text
旅行画家：
“明天我要去山顶，可天气似乎会变冷。”

↑ 请他注意安全
↓ 建议推迟一天
OK 送出一份热茶
```

选择不追求唯一正确答案，而是改变关系、后续事件和资源使用。

## 14. 新宠物加入

新伙伴通过相遇和故事加入，而不是以抽卡为主：

- 修复森林小屋后遇见受伤的狐狸。
- 连续在院子里摆放坚果，吸引松鼠来访。
- 完成渔夫系列订单后认识水獭。
- 暴雨中帮助负责送信的小狗。
- 高口碑后，旅行宠物申请成为临时帮工。
- 旅行队伍带回某位伙伴留下的信物。

新宠物会先短暂帮工，让玩家体验其能力和性格，再通过个人任务决定是否入住。

驿站床位有限，扩建后逐步增加。未入住的伙伴可以生活在小镇公共宿舍，不要求玩家抛弃宠物。

## 15. 随机事件

事件由岗位模板与宠物变量组合生成。一个事件可以因队伍不同产生不同结果。

示例：森林发光树事件。

- 狐狸在队：更可能判断为稀有材料。
- 狗在队：可能闻到附近走失旅客的气味。
- 鸟在队：可以先从空中观察。
- 胆小宠物：会建议立即返回，但也可能提前发现危险。
- 好奇宠物：可能擅自靠近，触发新的支线。
- 玩家同行：出现第三种主动处理方案。

错误选择不会造成无法挽回的损失，而会带来较低收益、宠物疲劳、搞笑事故或新的补救任务。

## 16. 小游戏

小游戏均服务于经营结果，单局控制在 20～60 秒。

### 16.1 烹饪火候

- 指针在火候条上移动。
- `UP / DOWN` 调整火力。
- `OK` 完成当前步骤。
- 表现影响料理品质，不会让珍贵材料完全消失。

### 16.2 河边钓鱼

- `UP / DOWN` 调整鱼钩高度或拉力。
- `OK` 收线。
- 宠物能力影响鱼出现的种类和容错范围。

### 16.3 客房整理

- 在有限时间内选择正确的三件用品。
- 旅客偏好与宠物感知会提供提示。
- 结果影响满意度与回访概率。

### 16.4 旅行辨路

- 根据声音、脚印和天气在两条路线间选择。
- `UP / DOWN` 选择路线，`OK` 使用道具。
- 队伍技能会揭示额外信息。

小游戏不是主要资源入口。不擅长小游戏的玩家也可以依靠宠物能力获得稳定结果。

## 17. 建设与世界成长

驿站分为五个阶段：

### 17.1 荒废小屋

- 前台、简易厨房、两张宠物床。
- 只能接待少量普通旅客。

### 17.2 森林驿站

- 开放农园、采集棚和正式客房。
- 森林道路恢复，动物旅客增加。

### 17.3 山路旅馆

- 开放工坊、仓库和商队订单。
- 山地旅行与矿物材料出现。

### 17.4 湖畔旅店

- 开放码头、钓鱼和水路运输。
- 举办更大型的季节节庆。

### 17.5 星光驿站

- 开放观星台、夜间客房和远方旅行。
- 成为各地旅人和宠物交换故事的中心。

每个阶段升级都永久改变主场景，包括楼层、招牌、窗户、花园、码头、路灯和活动角色。

## 18. 四季内容

### 18.1 春季：重新开始

- 作物：草莓、萝卜、豌豆、香草。
- 天气：小雨与晴天。
- 节庆：花种交换会。
- 故事主题：重新开张与认识邻居。

### 18.2 夏季：远行与热闹

- 作物：番茄、西瓜、向日葵。
- 天气：炎热、雷雨。
- 节庆：湖畔灯火祭。
- 故事主题：修复码头与迎接旅行旺季。

### 18.3 秋季：收获与选择

- 作物：南瓜、葡萄、小麦。
- 天气：大风、落叶。
- 节庆：丰收集市。
- 故事主题：库存、加工与商队竞争。

### 18.4 冬季：陪伴与回忆

- 普通农田暂缓，温室继续生产。
- 玩法重心转向料理、客房、旅行故事与关系。
- 节庆：雪夜团圆会。
- 故事主题：祖辈留下的旧信和驿站真正的历史。

冬季不是惩罚季，而是生产结构和叙事节奏的转换。

## 19. 主线故事

### 19.1 开端

玩家收到一封没有寄件人的旧信，回到多年无人居住的故乡。信中只有一句话：

> “路并没有消失，只是很久没有人替旅人点灯了。”

在废弃驿站门口，玩家遇见第一只宠物伙伴。它一直守着一块已经褪色的木牌，似乎在等待某个人回来。

玩家修好屋顶、点亮门灯，并在第一个雨夜接待了一位迷路旅客。第二天，门口出现一封感谢信和一枚属于旧驿站的印章。驿站由此重新开张。

### 19.2 第一章：重新点灯

玩家认识小镇居民，修复前台、厨房和第一间客房。越来越多旅客开始出现，新的宠物也因不同原因来到这里。

章节问题：这间驿站过去为何突然关闭？

### 19.3 第二章：断掉的道路

森林和山路仍有多处无法通行。玩家通过经营积累资源，组织宠物队伍修桥、送货和探索，逐渐恢复区域之间的联系。

旅行队伍发现祖辈曾沿途留下相同的星形标记。

章节问题：祖辈最后一次旅行去了哪里？

### 19.4 第三章：失去方向的旅人

多名回头客的故事开始交汇：寻找家乡的音乐家、送不出信的邮差、绘制不存在道路的画家，以及一只拒绝进入驿站的老狗。

玩家发现，驿站过去不只是旅馆，也负责保存旅行者的信件、地图和约定。

章节问题：经营驿站的意义是盈利，还是让人找到继续前进的方向？

### 19.5 第四章：冬夜旧信

冬季暴风雪封闭道路，玩家与伙伴共同接待被困的旅客。阁楼被风吹开，露出祖辈留下的旅行日记。

日记说明，祖辈并非失踪，而是为了寻找一条能让不同地区重新连通的旧路线而离开，并将驿站托付给“愿意继续点灯的人”。

### 19.6 终章：星光重新亮起

玩家修复观星台和最后一段道路。曾经帮助过的旅客与宠物在星光节再次回到驿站。玩家可以选择驿站未来的发展主题：

- 旅人之家：加强住宿、料理和人物故事。
- 伙伴工坊：加强生产、订单和建设。
- 远行协会：加强旅行、探索和收藏。

选择改变后续内容权重，但不关闭其他玩法。

主线结束后，第一位宠物伙伴会在门灯下说：

> “原来我们等的不是某个人回来。我们是在等这条路重新有故事。”

## 20. 代表性角色与故事钩子

### 20.1 第一位伙伴

可以由玩家从猫、狗或兔中选择。它是唯一会根据开局选择改变部分主线对话的角色。

- 猫：表面冷静，实际一直守护旧驿站。
- 狗：相信祖辈还会沿旧路回来。
- 兔：擅长修补庭院，害怕驿站再次被遗弃。

### 20.2 没有地址的邮差

一只年轻的鸟，每次都带着无法投递的信。完成它的任务后开放送货岗位。故事后期发现其中一封信正是寄给玩家的旧信。

### 20.3 只画背影的旅行画家

她从不画正脸，只记录旅人离开时的样子。随着多次来访，玩家会发现她正在寻找童年曾救过自己的宠物。

### 20.4 不肯住宿的老狗

它每逢雨夜都会出现在门外，却拒绝进入。需要由不同宠物逐步取得信任。它曾是祖辈最后一次旅行的队伍成员。

### 20.5 爱偷吃的熊厨师

能力优秀却总把失败归咎于炉子。它的个人故事不是改掉贪吃，而是学会把对味道的敏锐变成真正的料理天赋。

## 21. 图鉴与收藏

图鉴分为：

- 伙伴册：物种、个体故事、技能和关系照片。
- 旅客簿：来访记录、喜好和人物故事。
- 地区志：地点、天气、路线和旅行印章。
- 配方册：料理、加工品和发现过程。
- 纪念柜：旅客礼物与旅行纪念品。
- 驿站相册：建设前后、节庆和特殊合影。

未知条目应提供模糊线索，而不是只有问号，例如“在夏季雷雨后的湖边可能发现”。

## 22. 数值与收益原则

内部可以采用以下概念公式：

```text
最终收益
= 岗位基础收益
× 物种适性
× 属性效率
× 技能修正
× 状态修正
× 搭档协作
× 天气与事件
```

玩家界面只显示范围预测：

```text
预计产量：6～8
品质：较高
耗时：短
风险：低
成长：园艺经验较多
```

收益不只有金币：

- 金币收益。
- 资源收益。
- 宠物技能成长。
- 伙伴关系成长。
- 客人关系与口碑。
- 故事、照片和收藏。

因此低金币安排仍可能是有价值的选择。

## 23. 失败与保护机制

- 宠物不会因忽视死亡或永久离开。
- 作物错过收获不会立即消失，只会暂停或降低品质。
- 重要客人不会因十分钟内未登录而永远错过。
- 订单失败不会阻断主线，可以补救或等待再次出现。
- 旅行失败至少带回日记、经验或普通材料。
- 错误对话不以“坏结局”惩罚，而是开启不同后续。
- 修改设备时间不能重复领取关键奖励；异常时间只进行保守结算。

## 24. 美术与声音方向

### 24.1 像素视觉

- 温暖、低饱和的田园像素风格。
- 角色高度以 24～32 像素为主，优先保证轮廓辨识度。
- NPC通过帽子、耳朵、尾巴、背包和主色区分。
- 单个场景保留 3～5 个主要互动热点。
- 使用烟囱、窗灯、雨滴、落叶、猫尾、炉火等小动画表现生命感。
- 季节主要通过调色板、植物和装饰物变化，不依赖大量完整背景。
- 夜晚使用独立天空、窗灯和路灯色彩，而非简单降低亮度。

### 24.2 声音

- 四个时段拥有短小且可循环的主题旋律。
- 每种宠物拥有一组辨识度高的短音效。
- 旅行归来、稀有客人和建筑完成拥有独立提示音。
- 提醒应温和且可关闭，不使用高压力倒计时声音。

## 25. 首版 MVP

首版重点验证三个问题：排班是否有趣、离线回来是否有期待、宠物是否能形成情感辨识度。

建议范围：

- 1 名玩家角色。
- 5 个宠物物种：猫、狗、兔、熊、水獭。
- 8～10 只可结识的具体宠物。
- 4 个岗位：前台、厨房、农园、森林采集。
- 5 项属性、10 种性格、每宠最多 2 个技能。
- 双宠协作与关系成长。
- 春、夏两个季节，每季 14 个现实日。
- 6 种作物、8 种加工品、6 种料理。
- 8 名常驻或回头客、若干普通旅客模板。
- 30～40 个岗位事件。
- 2 个旅行地区，每个地区约 10 个事件节点。
- 6 个建设项目。
- 2 个小游戏：烹饪火候、河边钓鱼。
- 主线第一章“重新点灯”。

不建议首版加入：

- 自由移动的大地图。
- 战斗和复杂装备。
- 养殖动物的完整生产链。
- 三只以上宠物的复杂编队。
- 大量可输入数字的经济系统。
- 限时付费或强制联网社交。

## 26. MVP 的一个现实日示例

### 07:30

玩家打开设备：

- 领取夜间完成的面包。
- 查看天气：下午有雨。
- 安排兔子露露照料农园。
- 安排猫咪墨墨负责前台。
- 派狗狗阿麦和熊阿团进行 8 小时森林任务。
- 玩家亲自帮助厨房准备早餐。

约 3 分钟。

### 12:30

- 值班报告显示接待了三名旅客。
- 墨墨发现其中一位可能是美食评论家。
- 玩家决定赠送普通面包还是保留精品果酱。
- 农园因下雨自动完成浇水。

约 2 分钟。

### 18:00

- 森林队伍归来，带回木材、蘑菇和一张旧路牌照片。
- 阿团因好奇性格偏离路线，额外发现一处废弃营地。
- 驿站进入住宿高峰，玩家分配最后一间客房。
- 收入足够修复院子里的路灯。

约 5 分钟。

### 23:00

- 主场景显示大部分伙伴已经休息。
- 玩家安排阿团进行 8 小时面包加工。
- 墨墨自愿承担深夜值班，但第二天上午需要休息。

约 1 分钟。

## 27. 后续可扩展方向

- 矿洞与锻造，但仍使用路线选择而非自由战斗。
- 温室、湖泊、码头和观星台。
- 更多地区和旅行日记模板。
- 宠物间的导师与学徒关系。
- 本地 BLE 相遇：交换旅客明信片或让宠物短暂来访。
- 节庆中的双人合作小游戏。
- 自定义驿站招牌、房间主题和伙伴制服。
- 以更新包形式加入新旅客故事和地区，不破坏旧存档。

## 28. 需要优先验证的设计问题

1. 每天安排几只宠物、几个岗位最有趣而不繁琐？
2. 物种优势和性格事件的权重，能否避免唯一最优解？
3. 离线报告应展示多少内容，才既有惊喜又不显得冗长？
4. 真实时间任务的最舒适时长分布是什么？
5. 三键排班在小屏幕上是否能在 30 秒内完成？
6. 玩家会更在意金币效率、宠物故事，还是驿站外观成长？
7. 旅行日记需要多少视觉变化，才能让重复访问同一地区仍有期待？
8. 玩家连续数天未打开设备时，怎样欢迎其回来而不制造负罪感？

## 29. 核心设计原则总结

1. 真实时间制造期待，不制造惩罚。
2. 物种决定倾向，不锁死职业。
3. 性格同时带来优势与麻烦。
4. 宠物组合与关系比单一数值更重要。
5. 工作结果必须产出故事，而不只是资源。
6. 玩家亲自参与代表“今天选择陪谁”。
7. 不存在永久失败，失误应产生有趣后果或补救机会。
8. 所有长期成长都应在主场景中可见。
9. 三键操作保持简单，策略来自选择本身。
10. 驿站是所有系统的叙事中心；种植、制作、旅行和收集都应服务于旅人与伙伴的相遇。
